# AI Tracking Log

This document holds the project nodes, progress records, and summaries of completed session GOALs that C15 of the [conventions]({{link.conventions}}) defines. Every record is one line, and every time is the {{time.label}} value confirmed with the C12 time command. The form follows P9 of the [agent document patterns]({{link.patterns}}).

## Project nodes

The nodes that make up the project (C04 domain and class folders, C03 layers, C10 compiled areas) are managed one row each. A change that adds, moves, or removes a node or changes its dependencies corrects this table in the same task. The status is one of `planned`, `in progress`, and `verified`.
